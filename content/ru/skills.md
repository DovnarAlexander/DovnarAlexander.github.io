# Навыки

- Облачная архитектура: AWS (безопасность, сети, multi-account, FinOps), Azure, GCP
- Платформы: Kubernetes, ArgoCD, Helm; GitOps в масштабе
- AI-инжиниринг: разработка с AI-агентами (Claude Code, Cursor, Copilot), MCP-серверы и интеграции, агентные workflow и LLM-автоматизация
- CI/CD: GitHub Actions, GitLab CI, Jenkins; trunk-based разработка
- IaC: Terraform, Terragrunt, CDK, Pulumi; переиспользуемые модули, policy-as-code
- Observability: Prometheus, Grafana, OpenTelemetry; осмысленные SLO и алертинг
- Безопасность: IAM, управление секретами, SBOM, контроль supply chain
- Затраты: анализ потребления, right-sizing, автоскейлинг, устранение лишних расходов
- Как работаю: прагматичное лидерство, развитие команды, передача знаний
